# PQC Solana Wallet

Experimental Solana smart wallet development project.

## Development plan
1. Build a classical 2-of-3 approval vault.
2. Research on-chain post-quantum signature verification.
3. Integrate mandatory PQC authorization if feasibility tests pass.

## Current status
Initial repository setup. No wallet implementation yet.

## Scope
Local testing and Solana devnet only.
The initial classical multisig prototype is not quantum-resistant.
